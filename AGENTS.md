# VLA_project — входная точка для агента

Рабочий каталог на mark-pc — `/home/makarov_vd/VLA_project`.
Проект курса посвящён переносу политики захвата и перекладки с симуляции на SO-101.
Текущий этап — подготовка телеоперации и цифрового двойника. Проверенный запуск Sim выполняется через `./shmux.sh`, контейнер `vla-course-sim`, образ `vla-course:sim5.1.0-lab2.3.0`.

## Порядок чтения

1. Прочитай [RULES](instructions_for_agents/RULES.md) и краткий [MEMORY](instructions_for_agents/MEMORY.md).
2. Для текущей задачи выбери нужный документ из таблицы ниже.
3. Проверь применимые вложенные AGENTS.md, если они появятся, и живое состояние перед изменениями.

| Документ | Назначение |
|---|---|
| [PRD](instructions_for_agents/PRD.md) | Цель, требования преподавателя и критерии готовности |
| [ARCHITECTURE](instructions_for_agents/ARCHITECTURE.md) | Структура, компоненты и контракты между sim и real |
| [DESIGN](instructions_for_agents/DESIGN.md) | Постановка сцены, критерий успеха и план сравнения |
| [TASKS](instructions_for_agents/TASKS.md) | Приоритеты, исполнители, блокеры и проверка результата |
| [DATA](instructions_for_agents/DATA.md) | Пути, запись, метаданные, версии и разбиение данных |
| [WEIGHTS](instructions_for_agents/WEIGHTS.md) | Кандидаты моделей, источники и checkpoints |
| [COURSE_REQUIREMENTS](instructions_for_agents/COURSE_REQUIREMENTS.md) | Исходные требования, предоставленные пользователем |

## Git и ветки команды

Репозиторий — https://github.com/MakVlad2003/VLA_project.
`main` содержит основную согласованную версию кода, конфигураций и документации.
Каждый участник работает в ветке с именем своего ника, например `MakVlad2003`.
Изменения из личной ветки интегрируются в `main` через pull request после проверки.

На общем mark-pc основной checkout `/home/makarov_vd/VLA_project` остаётся на `main`.
Для одновременной работы используйте отдельные worktree в `~/VLA_worktrees/<ник>`.
Перед коммитом проверяйте ветку, worktree и персональную подпись автора.
Команды настройки приведены в README.

## Рабочие соглашения

- Для удалённого просмотра используй WebRTC Client 1.1.5 и `100.98.47.185`, TCP 49100 / UDP 47998. Версии, запуск и проверки описаны в README.
- Перед изменением окружения сначала проверь `./shmux.sh status` и логи.
- Код и небольшие конфигурации хранятся в проекте. Тяжёлые файлы доступны через `storage/` на общем диске Jetson.
- Работай в пределах запроса. До установки, обучения или работы с роботом проверь текущее окружение и процессы.
- Все коллеги используют один Linux-аккаунт. Согласовывай изменения пересекающихся файлов и занятые GPU/порты.
- Движения реального робота и запись настроек моторов выполняются в согласованной аппаратной сессии с оператором.
- Различай требования курса, предложения команды, проверенное состояние и гипотезы.
- Когда меняется состояние проекта, обновляй соответствующий центральный документ в той же задаче.
- В MEMORY сохраняй короткое актуальное резюме и ссылки на подробности. Ориентир — до 100 строк.

Команды для участников команды находятся в [README](README.md).
