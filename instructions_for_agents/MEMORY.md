## Открытые решения

- Конкретный SO-101, аппаратная сборка/калибровка и камера пока не проинвентаризированы в этом проекте.
- Объект, размеры стола, цель, критерий успеха, частота и представление действий предстоит согласовать.
- ACT/SmolVLA/другая политика ещё не выбрана. Проектных данных, checkpoints и результатов пока нет.
- Участники используют общий аккаунт. Из коллег в этой сессии добавлен публичный SSH-ключ Виталия. Вход с его компьютера не подтверждён.
- Публичный GitHub — https://github.com/MakVlad2003/VLA_project, origin — `https://github.com/MakVlad2003/VLA_project.git`.
- Основная ветка — `main`, личные ветки называются по нику. Ветка владельца — `MakVlad2003`, интеграция в main через PR.
- Общий checkout `~/VLA_project` остаётся на main. Параллельная работа ведётся в отдельных `~/VLA_worktrees/<ник>` с персональной Git-подписью через worktreeConfig.
- Первый push выполнен разовым deploy key с mark-pc. Ключ удаляется после публикации, дальнейшая аутентификация оформляется участниками.
- Распределение задач и GitHub-доступ коллег оформляет команда с владельцем.
